# Инструкция владельца: деплой v0.2.9 (24.10.2026)

Время: ~10 минут. Все команды — готовые блоки для вставки в PowerShell
(D20). Выполняйте строго по порядку. Если контрольная точка показала
не то, что ожидается, — ОСТАНОВИТЕСЬ и пришлите мне вывод команды в чат,
ничего не коммитите.

**В этом релизе миграций НЕТ** — меняется только раскладка интерфейса
(фиксированный сайдбар 280px, правые панели 320px). Схема базы не
трогается. Первый вход на главной покажет новую трёхколоночную схему.

**Важно:** публикуем релиз только командами git из PowerShell.
Загрузка файлов через сайт GitHub (кнопка «Add file → Upload files»)
для релизов запрещена.

## 0. Привести клон в чистое состояние

Откройте PowerShell и скопируйте блок целиком:

```powershell
cd C:\PROJECTS\logix
git rebase --abort
git merge --abort
git fetch origin
git reset --hard origin/main
git clean -fd
git log --oneline -1
git status
```

Пояснения:

- «No rebase/merge in progress» в ответе — нормально, идите дальше.
- `git reset --hard origin/main` + `git clean -fd` делают клон точной
  копией GitHub. Ваш `.env` не пострадает — он игнорируется git.
- **Контрольная точка 0:** `git log --oneline -1` должна показать
  `08eef2e release v0.2.8: …`. `git status` — «working tree clean».
  Если лог показывает другой коммит — пришлите мне вывод всего блока,
  ничего не делайте дальше.

## 1. Распаковать релизный архив в клон

Скачайте `logix-v0.2.9.zip` из чата в папку `C:\PROJECTS\logix`,
затем скопируйте блок целиком:

```powershell
Remove-Item .\logix-v0.2.8.zip -ErrorAction SilentlyContinue
Expand-Archive -Path .\logix-v0.2.9.zip -DestinationPath . -Force
```

Файлы лягут поверх клона с заменой. Ошибка «файл занят/используется» —
закройте редакторы, которые могли открыть файлы проекта, повторите блок.

## 2. Контрольная точка 1: версия архива

```powershell
Select-String -Path .\package.json -Pattern '"version"'
```

**Ожидается:** `"version": "0.2.9"`.

Другая версия — распаковался не тот архив или не в ту папку.
ОСТАНОВИТЕСЬ, пришлите мне вывод этой команды и `Get-ChildItem .\*.zip`.

с `src/` или появились лишние — ОСТАНОВИТЕСЬ, пришлите мне полный вывод
`git status --short`.

## 4. Закоммитить и запушить

Только если контрольные точки 1–2 совпали:

```powershell
git add -A
git commit -m "release v0.2.9: P1-18 брендбук B - workspace 280/1fr/320 (фикс-сайдбар Sand + правые панели События/Журнал, складывание <1280px, без миграций)"
git push origin main
```

Пуш должен пройти без ошибок. Если отклонился — НЕ делайте `git pull`
сами, пришлите мне текст ошибки в чат.

## 5. Проверить состав коммита на GitHub (контрольная точка 3)

Откройте https://github.com/alfat81/logix/commits/main — верхний коммит
`release v0.2.9: …`. Зайдите в него: должно быть написано
**«9 files changed»**, в списке есть `SideActivityFeed.tsx`,
`src/app/admin/(dashboard)/layout.tsx`, `LeadCard.tsx` и `package.json`.

## 6. Дождаться зелёного CI (GitHub → Actions)

CI должен быть зелёным, включая «Unit-тесты (vitest)» и «e2e API
(PostgreSQL)». Красный — не паникуем: пришлите лог (Actions → упавший
job → Copy raw logs). Откат одной командой:

```powershell
git revert HEAD --no-edit
git push
```

База при откате не затрагивается — миграций в релизе нет.

## 7. Дождаться деплоя Vercel

Deployments → последний коммит → Status: Ready. Новые env-переменные
не требуются, Redeploy вручную не нужен.

## 8. Smoke на проде (~5 минут)

1. Открыть `<ваш-адрес>/api/health` → `{"status":"ok","db":"ok"}`,
   поле `version` — новый SHA (не `08eef2e`).
2. Войти мастером. **Сайдбар стал фиксированной панелью 280px** (тёплый
   песочный фон), логотип и разделы сверху, «Мастер Logix» и «Выйти» —
   внизу панели; поиск остался в шапке.
3. **Главная:** трёхколонная схема — «Требует внимания» в центре,
   справа колонка «События» (свежие действия по всем сделкам, у заметок
   коралловая линия слева).
4. **Лид:** откройте любой лид → справа sticky-панель: «Внутренняя
   заметка» и «Журнал событий» (как раньше, но в правой колонке);
   анкета и варианты — в центре. Прокрутите анкету — правая панель
   остаётся на виду.
5. **Узкий экран:** сузьте окно примерно до 1000px — правая колонка
   складывается вниз, ничего не ломается; на телефоне (375px) — меню
   полосой сверху, как было.
6. **Данные не изменились:** суммы, варианты, журналы — прежние.

Домен может быть недоступен из России без VPN (решение D17) — это не
признак поломки.
