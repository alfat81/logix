# Инструкция владельца: деплой v0.2.8 (24.10.2026)

Время: ~10 минут. Все команды — готовые блоки для вставки в PowerShell
(D20). Выполняйте строго по порядку. Если контрольная точка показала
не то, что ожидается, — ОСТАНОВИТЕСЬ и пришлите мне вывод команды в чат,
ничего не коммитите.

**В этом релизе миграций НЕТ** — меняется только фронтенд (палитра,
шрифт, радиусы). Схема базы не трогается, шаг с `prisma migrate deploy`
отсутствует. Первый деплой на Vercel может собираться на несколько
секунд дольше обычного — при сборке скачивается шрифт IBM Plex Sans
с Google Fonts; это нормально, ничего делать не нужно.

**Важно:** публикуем релиз только командами git из PowerShell.
Загрузка файлов через сайт GitHub (кнопка «Add file → Upload files»)
для релизов запрещена.

## 0. Привести клон в чистое состояние

Откройте PowerShell и скопируйте блок целиком:

```powershell
cd C:\PROJECTS\logix
git rebase --abort
git merge --abort
git fetch origin
git reset --hard origin/main
git clean -fd
git log --oneline -1
git status
```

Пояснения:

- «No rebase/merge in progress» в ответе — нормально, идите дальше.
- `git reset --hard origin/main` + `git clean -fd` делают клон точной
  копией GitHub. Ваш `.env` не пострадает — он игнорируется git.
- **Контрольная точка 0:** `git log --oneline -1` должна показать
  `a95e65c release v0.2.7: …`. `git status` — «working tree clean».
  Если лог показывает другой коммит — пришлите мне вывод всего блока,
  ничего не делайте дальше.

## 1. Распаковать релизный архив в клон

Скачайте `logix-v0.2.8.zip` из чата в папку `C:\PROJECTS\logix`,
затем скопируйте блок целиком:

```powershell
Remove-Item .\logix-v0.2.7.zip -ErrorAction SilentlyContinue
Expand-Archive -Path .\logix-v0.2.8.zip -DestinationPath . -Force
```

Файлы лягут поверх клона с заменой. Ошибка «файл занят/используется» —
закройте редакторы, которые могли открыть файлы проекта, повторите блок.

## 2. Контрольная точка 1: версия архива

```powershell
Select-String -Path .\package.json -Pattern '"version"'
```

**Ожидается:** `"version": "0.2.8"`.

Другая версия — распаковался не тот архив или не в ту папку.
ОСТАНОВИТЕСЬ, пришлите мне вывод этой команды и `Get-ChildItem .\*.zip`.

## 4. Закоммитить и запушить

Только если контрольные точки 1–2 совпали:

```powershell
git add -A
git commit -m "release v0.2.8: P1-17 брендбук A - токены+шрифт (палитра Ivory/Sand/Coral/Brick/Ink + IBM Plex Sans + радиусы 12/8, без миграций)"
git push origin main
```

Пуш должен пройти без ошибок. Если отклонился — НЕ делайте `git pull`
сами, пришлите мне текст ошибки в чат.

## 5. Проверить состав коммита на GitHub (контрольная точка 3)

Откройте https://github.com/alfat81/logix/commits/main — верхний коммит
`release v0.2.8: …`. Зайдите в него: должно быть написано
**«12 files changed»**, в списке есть `src/app/globals.css`,
`src/app/layout.tsx`, `src/components/ui/button.tsx` и `package.json`.

## 6. Дождаться зелёного CI (GitHub → Actions)

CI должен быть зелёным, включая «Unit-тесты (vitest)» и «e2e API
(PostgreSQL)». Красный — не паникуем: пришлите лог (Actions → упавший
job → Copy raw logs). Откат одной командой:

```powershell
git revert HEAD --no-edit
git push
```

База при откате не затрагивается — миграций в релизе нет.

## 7. Дождаться деплоя Vercel

Deployments → последний коммит → Status: Ready. Сборка может идти
чуть дольше обычного (скачивание шрифта) — это нормально. Новые
env-переменные не требуются, Redeploy вручную не нужен.

## 8. Smoke на проде (~5 минут)

1. Открыть `<ваш-адрес>/api/health` → `{"status":"ok","db":"ok"}`,
   поле `version` — новый SHA (не `a95e65c`).
2. Войти мастером. Общий фон приложения — тёплый белый (Ivory),
   карточки — белые со скруглением 12px.
3. **Шрифт:** правый клик → «Просмотреть код» на любом заголовке →
   Computed → `font-family` начинается с `IBM Plex Sans`.
4. **Кнопки:** главные действия («Конвертировать в заявку»,
   «Добавить вариант») — коралловые `#F28C8C` с белым текстом,
   скругление 8px; вторичные («+ Загрузить документ») — прозрачные
   с тёплой рамкой; удаление варианта — кирпичный `#D95D39`.
5. **Данные не изменились:** карточка варианта показывает
   «10 000 $ · без НДС», как и раньше; поиск, фильтры, журналы работают.
6. **Не менялось (ожидаемо):** сайдбар визуально прежний (его перекрасит
   этап B — P1-18), бейджи статусов прежние (этап C — P1-19).

признак поломки.
