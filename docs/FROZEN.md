# FROZEN — замороженные области (D31, создаётся DF-00B, наполняется DF-00C)

Замороженное (D31): не развивается, не удаляется, из проверок G4 (knip, роуты без
потребителя) исключено. Правка файла из замороженного глоба — нарушение `scope.py check`
без метки `"unfreeze": true` в `docs/releases/SCOPE-vX.Y.Z.json`. Разморозка — только
записью владельца. Проверки IC-02/IC-03, компиляция и e2e (с включённым флагом
`CONTRACTOR_PORTAL_ENABLED`) продолжают действовать.

До DF-00C файл существует пустым — проверка формата IC-12 допускает отсутствие строк
в таблице, но требует самой таблицы.

| Глоб | Причина | Дата | Условие разморозки |
|---|---|---|---|
| (заполняется в DF-00C) | кабинет подрядчика заморожен по D31 | — | решение владельца (D31) |
