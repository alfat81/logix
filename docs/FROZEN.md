# Замороженные области (D31)

Кабинет подрядчика заморожен решением владельца (D31, 25.10.2026): не
развивается, не рефакторится, не «чистится». Код не удаляется — он
понадобится при разморозке. По умолчанию кабинет выключен флагом
`CONTRACTOR_PORTAL_ENABLED` (false): `src/proxy.ts` отвечает 404 на все
пути `/contractor/**`, `/api/contractor/**`, `/api/auth/contractor/**`
до любой логики, cookie подрядчика (`logix_contractor_session`) не
обрабатывается, ссылка на вход с лендинга скрыта.

Правила: ROADMAP-DEALFLOW §4.3 (п.8) и §4.7 п.8. Изменять перечисленное
без метки `"unfreeze": true` в `SCOPE-vX.Y.Z.json` — нарушение (scripts/scope.py).
IC-02/IC-03, компиляция и e2e (с включённым флагом в CI) продолжают действовать.
Разморозка — только записью владельца в DECISIONS.md.

## Замороженное вне файловых глобов (не развивать, правки файла допустимы)

- Ветка `kind: 'contractor'` в `src/lib/login-guard.ts` — файл живой
  (общая логика лимитов), но подрядная ветка не развивается; удаляется
  только при разморозке/удалении кабинета.
- Блок «contractor» в `scripts/e2e_api_test.py` (рождение подрядчика,
  назначение на этап, кабинетные проверки) — фиксируется как регресс
  при `CONTRACTOR_PORTAL_ENABLED=true`; новые проверки кабинета не
  добавляются.

  (вместо стартового пароля клиент генерирует случайный, API не меняется).
