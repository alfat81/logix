# Logix — Брендбук и руководство по эргономике

Версия 1.1 · Утверждён владельцем 24.10.2026 · Обязателен при любых изменениях UI (RULES 2.14)

Источник: утверждённый гайд «Logix — Руководство по эргономике ИИ-агента»
(Version 1.1, передан владельцем в чате 24.10.2026). Как сказано в самом
гайде — «системный промпт для ИИ, работающего над платформой Logix»: все
новые экраны, формы и карточки проектируются строго по этому файлу.

Пункты с пометкой «Дополнение агента» в исходном гайде отсутствуют — это
зафиксированные мной недостающие значения, чтобы документ был применим
без домысливания. Владелец может скорректировать их в любой момент
(список — §8); правится только этот файл.

### 1.2 Типографика — IBM Plex Sans

Шрифт с открытой апертурой: обеспечивает читаемость мелких цифр и
технических терминов в таблицах.

| Уровень | Начертание | Настройки |
|---|---|---|
| Заголовки | Bold / 700 | tracking-tight |
| Основной текст | Regular / 400 | leading-relaxed |
| Данные (цифры, суммы, номера) | Medium / 500 | tabular-nums — «monospaced-feel»: равная ширина цифр; сам шрифт не моноширинный |

Подключение: `next/font/google` (IBM Plex Sans, веса 400/500/700,
подмножества `latin` + `cyrillic`, `display: swap`), fallback — system-ui.
Шрифт задаётся в `layout.tsx` и привязывается к `--font-sans`.

## 2. Принципы эргономики

1. **Плотность данных.** Компактные таблицы с минимальными отступами,
   но чёткими границами разделов. Важна не пустота, а иерархия.
2. **Версионность документов.** Любое изменение документа визуально
   помечается тегом версии. Переключение между версиями — не более 2 кликов.
3. **Контекстный фокус.** Трёхколоночная вёрстка
   (Навигация | Список | Детали), чтобы пользователь никогда не терял контекст.

## 4. Правила вёрстки окон (Workspace)

1. **Навигация (280px):** фиксированная левая панель. Группировка по
   ролям (Admin, Client, Broker).
2. **Список (1fr):** основная рабочая область. Карточки заявок с
   индикатором статуса.
3. **Детали/Чат (320px):** правая панель. Документы, события и мессенджер.

Пропорции: 280px | 1fr | 320px.
Адаптив гайд не задаёт: при ширине < 1280px третья колонка складывается
(решение фиксируется при применении, §7 этап B).

## 5. Логика ИИ-агента (System Instructions for Generation)

При генерации новых форм и карточек:

1. Скругления: 12px для карточек и 8px для кнопок.
2. Фон всех форм — `#FFFFFF` (White) для контраста с Ivory.
3. Ошибки и критичные задержки подсвечивать `#D95D39` (Brick).
4. Все кнопки «Подтвердить/Создать» — `#F28C8C` (Coral).
5. Для вторичных действий — прозрачный фон и рамка `#E5DCC5`.

Примечание: в исходнике п. 3 читался как «все отступы/критичные
задержки» — по смыслу палитры (Brick = Alerts) зафиксировано как
«ошибки и критичные задержки»; подтверждение владельца — §8.

## 6. Отображение на код

- `globals.css`: `--radius: 0.75rem` (12px); переменные `--ivory`,
  `--sand`, `--coral`, `--brick`, `--ink`, `--success`, `--border-sand`;
  маппинг shadcn: `--background`→Ivory, `--card`/`--popover`→White,
  `--primary`→Coral, `--destructive`→Brick, `--border`→Border-Sand,
  `--foreground`→Ink, сайдбар→Sand.
- `layout.tsx`: IBM Plex Sans через `next/font/google` → `--font-sans`.
- `ui/button.tsx`: default→Coral, destructive→Brick,
  outline/secondary→рамка `#E5DCC5`.
- `ui/badge.tsx`: статусные варианты из §3.2.
- Числа в таблицах и суммах: `tabular-nums` + Medium 500.
- Кнопки 8px при `--radius: 12px` — через производные токены
  (`--radius-sm/md`); финальная развязка — в этапе A (§7).
- Ограничения RULES 2.14 сохраняются: только `src/components/ui`,
  новые hex — только в `globals.css`, файл ≤ 300 строк.

## 7. Порядок применения (отдельные UI-релизы)

Репаинт не смешивается с функциональными релизами: очередь Фазы 1
(P1-04 «Деньги») не сдвигается.

- **Этап A «Токены и шрифт»:** палитра, шрифт, радиусы (`globals.css` +
  `layout.tsx` + `ui/*`) — repaint без перестройки структуры; e2e не
  затрагивается (тексты и локаторы те же).
- **Этап B «Трёхколоночный workspace»:** фиксированная навигация 280px,
  списки 1fr, правая панель 320px; складывание третьей колонки на узких
  экранах.
- **Этап C «Статусы и теги»:** бейджи по §3.2 во всех списках; печатные
  формы — чёрный/брендовые токены (print.css).
