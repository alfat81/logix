# Релиз v0.2.7 — P1-04 «Деньги: валюта, НДС, себестоимость» (24.10.2026)

## Что внутри

- **Деньги в вариантах расчёта (P1-04):** цена клиенту — `Decimal(14,2)` с
  валютой (RUB/USD/EUR/CNY) и меткой НДС («с НДС / без НДС / НДС 0%»);
  себестоимость — отдельные поля, видимые только сотрудникам (D19: цена
  и себестоимость хранятся раздельно, маржа не вычисляется).
- **`lib/money.ts`** — единственная точка форматирования и разбора денег
  (RULES 2.15): «1 450 ₽» / «1 450,50 $», разбор ввода «1 450,50»,
  валидация до 2 знаков после запятой. Локальные копии форматтеров удалены.
- **Оценка брокера** — Decimal (дробные суммы разрешены, валюта RUB по
  природе платежа — ТК ЕАЭС).
- **Изоляция (приёмка):** клиент, брокер и подрядчик не видят
  себестоимость — проверено e2e на все три кабинета; в снимок заявки
  себестоимость не попадает.
- **UI:** форма варианта — цена/валюта/НДС/себестоимость; карточка
  варианта — «1 200 000 ₽ · с НДС»; условия заявки — с валютой; печатная
  форма п.23 — цена с валютой и НДС. Секция вариантов вынесена из
  LeadCard в три компонента ≤ 300 строк (RULES 2.14).
- **Брендбук прописан** (D22/D23): `docs/BRANDBOOK.md` v1.1 — источник
  правды по UI; обязательная сверка в RULES 2.14 и в шаге 1 конвейера
  (RULES 2.16). Репаинт интерфейса — P1-17…P1-19, следующая очередь.
- **Миграция №3** `20261024170000_p1_04_money`: типы денег → Decimal +
  enums Currency/VatMode + колонки себестоимости; дефолты RUB/«без НДС» —
  существующие значения не теряются, backfill не требуется.
