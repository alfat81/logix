## Шаг 5. Smoke (прод)

1. `/api/health` — `{"status":"ok","db":"ok"}`.
2. Вход сотрудником → заявка в «Расчёте», у которой назначен и идёт этап (или стоит «Проблема»): под шапкой строка «Работа началась — перевести в „В работе“?» с кнопкой. Нажать → тост, статус «В работе», подсказка исчезла.
3. Заявка в «В работе» со всеми завершёнными этапами: строка «Все этапы завершены — завершить заявку?». Нажать → статус «Завершена».
4. Негатив: заявка в «Расчёте» без тронутых этапов (все «Не начат») — подсказки нет; заявка «Завершена» — подсказок нет; заявка в «В работе» с незавершёнными этапами — подсказки нет.
5. Проверка критерия приёмки: подсказка не появляется там, где матрица запрещает переход (например, «Расчёт» + все этапы завершены → предлагается только «В работе», а не «Завершена»).
6. Мобильный (375 px): строка подсказки переносится по `flex-wrap`, ничего не выходит за экран.
7. Клиентский кабинет без изменений: подсказка — внутренний инструмент сотрудника, наружу не отдаётся (новых API нет).
