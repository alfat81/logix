# Logix — релиз v0.2.1 (24.10.2026)

Технический релиз поверх v0.2.0: изменений в коде приложения нет.
v0.2.0 не публиковался (пуш владельцем не выполнялся), поэтому по правилу
«patch на каждый релизный архив» (RULES 2.16) состояние пересобрано и
помечено как v0.2.1. Публиковать нужно именно его.

## Что внутри

- Всё из v0.2.0: статусная модель заявки и запроса (P1-05) и валидация
  дат этапов (P1-06). Бизнес-описание — в `RELEASE-NOTES-v0.2.0.md`.
- Зафиксирован формат инструкций по деплою (решение D20): команды для
  владельца — готовые блоки для вставки в PowerShell (Windows),
  без bash-специфики. Формат закреплён в `docs/RULES.md` 2.16 (шаг 1),
  статус-блоке `docs/ROADMAP.md` и `docs/DECISIONS.md` (D20); все
  будущие RELEASE-INSTRUCTIONS оформляются только так.

CHANGELOG/релизные файлы) и номер версии.
