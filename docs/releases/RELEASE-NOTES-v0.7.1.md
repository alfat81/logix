# RELEASE-NOTES v0.7.1

Задача DF-20 «Визуальные правила: контраст, красный сигнал, мобильные правила» (позиция 1д очереди; зависимость DF-00B). Версия пакета: 0.7.0 → **0.7.1** (patch, RULES 2.16). Миграций нет, новых env нет, сид не требуется — релиз только про использование цветов интерфейса и автопроверку; API и поведение не менялись.

## Причина

Разбор набросков владельца (26.10, UXPILOT-BRIEF) показал: (1) нечитаемые пары брендбука v1.2 — белый текст на Coral 2,36 к 1 (основные кнопки), Coral-текст на тинтах 2,04, белый на Brick 3,77 — при требовании WCAG AA 4,5; (2) «красный шум» — Brick/Coral в логотипе, активном пункте меню, обычных этапах и баннерах, из-за чего красный перестал означать срочное (режим красных писем DF-03 теряет смысл); (3) подписи 10px в 13 компонентах. Палитру, шрифт и скругления НЕ меняем — правим использование.

Проход существующих экранов на 375px — список расхождений в отчёте: нет нижней навигации 64px (сейчас strip под шапкой), детали диалогами вместо полноэкранного листа, нет липкой основной кнопки, цели касания меню ~36px < 44px, toast w-[420px] шире 375, сетка итогов расчёта 5 колонок без мобильного фолбэка, фильтры списков всегда развёрнуты. Скриншоты 1440/375 «до/после» в песочнице не снимались (ограничение браузерного агента — гидрация dev-сервера, урок fix1); визуальную проверку делает владелец на смоук-шаге.
