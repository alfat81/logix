# RELEASE NOTES v0.6.7 — DF-17 «Справочники и курсы: платформа, страны, валюты, упаковка, Инкотермс, курсы ЦБ РФ»

Дата: 28.10.2026 · База: v0.6.6 (`aeb4bc9`) · Оценка карточки: 4 д

## Что меняется для владельца

**Свободный текст в полях маршрута и упаковки уходит.** Страны, валюты, упаковка
и условия поставки теперь выбираются из справочника во всех формах — поиска,
группировки по маршрутам и будущих расчётов (DF-18/DF-19) больше не ломает
разнобой «Шанхай / Shanghai / Шанхай порт». Курсы ЦБ РФ загружаются ежедневно
проходом диспетчера — ручной ввод курса не нужен.

| Что появилось | Где |
|---|---|
| Экран «Справочники» | `/admin/references` — доступен мастеру и менеджеру; пункты меню нет — раздел открывается по ссылке (меню поедет в DF-21 по макетам) |
| Страны (249) | ISO 3166-1: alpha-2, alpha-3, цифровой код; русские названия — ICU, ВЭД-терминология переопределена (Гонконг, Южная Корея и т. п.) |
| Валюты (32) | ISO 4217 с числом знаков; по умолчанию включены RUB, USD, EUR, CNY — остальные включает мастер |
| Упаковка (24) | Ходовые виды Рек. 21 ЕЭК ООН (PX — поддон, CT — коробка картонная, BG — мешок…); коды взяты из источника |
| Условия поставки | 11 терминов Инкотермс 2020 + DAT 2010 (неактивен, «по запросу»); разъяснение своими словами рядом с выбором |
| Курсы ЦБ РФ | Импорт раз в сутки проходом диспетчера; при сбое — последний известный курс с пометкой даты |

## Принципы, которые стоит знать

- **Коды не меняются.** У записи справочника правятся подпись, активность и
  порядок; код править нельзя (API отклоняет с 400) — сделки ссылаются на код,
  снимки старых заявок остаются валидными.
- **Активность на момент действия.** Отключённая мастером валюта исчезает из
  форм для новых строк, но существующие сделки не переписываются задним числом.
- **Запасной список валют.** Если таблица справочника пуста (свежий деплой без
  сида), формы работают на четырёх запасных валютах — сломать ввод невозможно.
- **Инкотермс — собственные формулировки.** Тексты Правил ICC не копируются и
  не переводятся (проверена политика ICC по копирайту и товарному знаку);
  разъяснения — независимые, «Incoterms®» — с символом ® в подсказках. Таблица
  правил для таможенной стоимости помечена «черновик, на утверждении» — её
  утверждает брокер до включения расчёта (O-12, DF-19).
- **Источники и условия использования** каждого справочника зафиксированы в
  `docs/REFERENCES-SOURCES.md` (гард IC-16 проверяет покрытие): ISO — только
  коды-факты, Рек. 21 — официальный классификатор ЕЭК ООН, курсы ЦБ — открытые
  данные с указанием источника в интерфейсе.

## Для клиентов и брокеров

Клиент в форме запроса выбирает страну и (необязательно) условие поставки —
с разъяснением рядом, без знания терминов. Брокер читает справочники (упаковка
— коды Рек. 21). Неактивные записи в кабинетах клиента и брокера не видны.

## Технические заметки

- Миграция `df_17_references` — additive: две новые таблицы + nullable
  поля-коды на `Lead`/`Order`; легаси-текстовые поля остаются рядом, старые
  заявки открываются без изменений.
- `CURRENCIES` в `money.ts` стал запасным списком на случай пустой таблицы;
  единственный источник выбора валюты — справочник в БД.
- Импорт курсов: `lib/cbr.ts` разбирает официальную выгрузку ЦБ РФ
  (`XML_daily.asp`, windows-1251, запятая как десятичный разделитель, номинал);
  выключатель `CBR_IMPORT=off` — для CI/e2e; новый env `CBR_RATE_URL` — только
  для переопределения адреса (обычно не задаётся).
- Формат и время публикации курсов ЦБ проверены 28.10.2026: публикация, как
  правило, до ~15:30 МСК, установленный курс действует со следующего дня.
- Диспетчер уведомлений теперь сначала тянет курсы (раз в сутки) — сбой
  импорта НЕ валит проход диспетчера.
