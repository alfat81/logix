# Logix — релиз v0.2.2 (24.10.2026)

Технический релиз: изменений в коде приложения НЕТ относительно
проверенного состояния (`tsc`/`eslint`/vitest/build чисто, e2e 61/61).
Публикуется вместо так и не запушенных v0.2.0/v0.2.1.

## Что внутри

- Фаза 0 целиком + **P1-05** (статусная модель заявки и запроса) +
  **P1-06** (валидация дат этапов) — бизнес-описание в
  `RELEASE-NOTES-v0.2.0.md`.
- Формат инструкций по деплою зафиксирован (решение D20): команды для
  владельца — готовые блоки для вставки в PowerShell, без bash-специфики.
- RULES 2.16 (шаг 2) дополнен обязательным шагом «синхронизировать клон
  с GitHub ПЕРЕД распаковкой архива».

## Почему v0.2.2, а не v0.2.0/v0.2.1

Первый пуш 24.10 был сделан из локального клона, отставшего от GitHub:
23.10 Фаза 0 уже была запушена через PR #2–#4, а клон остался на
состоянии до них. Push отклонился, `git pull --rebase` застрял на
конфликтах. На самом GitHub ничего не сломано и не потеряно: сравнение
дерева v0.2.2 с GitHub показало, что в нём есть всё содержимое remote
плюс новые задачи (P1-05/P1-06, vitest, документы) — remote-версии
файлов являются подмножеством. Пуш v0.2.2 поверх текущего GitHub
проходит без конфликтов.
