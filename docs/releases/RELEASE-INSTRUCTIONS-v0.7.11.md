## Шаг 6. Смоук на проде (≤ 10 минут)

1. **Админка → карточка запроса**: секция «Разрешительные документы» на месте (пустое состояние — muted-строка); «Добавить» открывает диалог (название, кто предоставляет, блокирует ли, срок); создать строку → событие в ленте, строка pending.
2. **«Править»**: сменить срок/поставщика; «Не требуется» без причины — 400; с причиной — строка version-бейдж «Не требуется».
3. **Карточка заявки**: та же секция между брокерами и этапами; загрузить файл прямо в строке → статус «Получен», в ленте событие, в «Документах» появился документ типа «Разрешительный».
4. **«У кого мяч»**: у заявки с pending-строкой от клиента плашка «Ждёт: клиента»; после загрузки файла мяч освобождается (проверить на тестовой сделке).
5. **Кабинет клиента**: в заявке секция «Разрешительные документы» с плашкой «Ожидается: … — от вас…»; загрузить документ → строка «Получен»; удалить документ в админке → строка вернулась в ожидание.
6. **Кабинет брокера**: строки наружной проекцией (без внутренней заметки), добавление строки брокером, закрытие своим файлом.
7. **Чужая сделка** (второй аккаунт): прямые запросы к чужой строке — 404.
8. **Настройки**: «Уведомления» — `notifications.red_event_types` по умолчанию содержит `permit_overdue` (только у мастеров на «Настройках» — не менять на проде без нужды).
9. **Письма**: у сделки с блокирующей строкой и прошедшим сроком — красное письмо «Срочно: …» тому, кто должен предоставить, и ответственному; повтор через минуту — без дубля.

Расхождение любого пункта — скриншот в чат агенту.
