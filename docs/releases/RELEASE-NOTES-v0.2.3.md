# Logix — релиз v0.2.3 (24.10.2026)

Технический релиз: изменений в коде приложения НЕТ относительно
проверенного состояния (`tsc`/`eslint`/vitest/build чисто, e2e 61/61).
Публикуется вместо так и не опубликованного v0.2.2.

## Что внутри

- Фаза 0 целиком + **P1-05** (статусная модель заявки и запроса) +
  **P1-06** (валидация дат этапов) — бизнес-описание в
  `RELEASE-NOTES-v0.2.0.md`.
- Формат инструкций по деплою — готовые блоки PowerShell (D20).

## Почему v0.2.3, а не v0.2.2

Коммит v0.2.2, ушедший на GitHub 24.10 (`bb30bdf`), оказался неполным:
в нём только 4 файла релизной документации, без единого файла кода
(`package.json` на GitHub — 0.1.0, `status-machine.ts` отсутствует).
Vercel успешно задеплоил это состояние (лог зелёный) — то есть
«проблемы деплоя» не было, но на проде остались только функции Фазы 0.

RULES 2.16 (шаг 2) усилен обязательными контрольными точками владельца:
проверка версии `package.json` после распаковки, проверка состава
`git status --short` перед коммитом (ожидаемый список — в инструкции),
запрет публикации через веб-интерфейс GitHub. `.gitignore` дополнен
`*.zip` (архивы не публикуются через репозиторий).
