# RELEASE-NOTES v0.5.5 — Фикс e2e-заморозки: лендинг читает флаг в рантайме (26.10.2026)

Дата: 26.10.2026. Задача: добивание зелёного CI после v0.5.4.
Пользовательских функций нет — инфраструктурный фикс. Версия: 0.5.5 (patch).

## Симптом

Прогон v0.5.4 впервые дошёл до шага «Сквозной тест заморозки»: основной
e2e **149/149** — фикс мок-базы сработал. Заморозка дала **15/16**:

```
FAIL на лендинге нет ссылки «Вход для подрядчиков»
```

При этом четыре 404-проверки кабинета и рождение подрядчика — PASS.

## Корень

Лендинг (`src/app/page.tsx`) — серверный компонент без директив динамики:
Next.js **пререндерил его в статику** и вшил значение
`CONTRACTOR_PORTAL_ENABLED` в HTML на этапе `next build`. В CI сборка
идёт с флагом `true` (job-level env нужен основному e2e), поэтому
перезапуск сервера шагом заморозки с `false` ссылку из кэша сборки
убрать не мог. Локально дефект не воспроизводился: приёмка v0.5.4
собиралась без флага — HTML без ссылки, заморозка 16/16.

На проде проявлений нет: флаг не задан, пререндер без ссылки. Дефект
CI-механический, но это ещё и нарушение заявленного контракта
`src/lib/flags.ts`: «смена env не требует пересборки».

## Что сделано

`export const dynamic = "force-dynamic"` в `src/app/page.tsx` — лендинг
рендерится на каждый запрос, `contractorPortalEnabled()` читается в
рантайме. Из трёх потребителей флага `proxy.ts` — всегда runtime,
страница «Подрядчики» — динамическая из-за auth; лендинг был
единственной статикой. Основной e2e HTML лендинга не проверяет — не задет.
Цена: лендинг рендерится на каждый запрос — страница без обращений к БД,
для служебной системы приемлемо.

## Приёмка (конфигурация CI — сборка с флагом=true, без пересборки перед заморозкой)

- tsc 0, eslint 0, build — зелёные; вывод сборки: маршрут `/` стал
  `ƒ` (dynamic) вместо `○` (static).
- Чистая БД, миграции → сид → сервер (`CONTRACTOR_PORTAL_ENABLED=true`) →
  основной e2e **149/149**.
- Перезапуск сервера (`false`, `DISABLE_RATE_LIMIT=true`) БЕЗ пересборки →
  заморозка **16/16** — включая «на лендинге нет ссылки», падавший в CI.
