# Logix — инструкция для UX Pilot (корректировка макетов)

Версия 1.0 · 26.10.2026 · положить в `docs/design/UXPILOT-BRIEF.md`
Основа: наброски владельца (лендинг, гайд, экран «Заявки»), `docs/BRANDBOOK.md`, роадмап `ROADMAP-DEALFLOW.md` (карточки DF-20, DF-21).

## 0. Как пользоваться

1. Откройте проект в UX Pilot. В **каждый** промпт вставляйте блок «1. Глобальный стиль» целиком (или сохраните его как общие правила проекта, если сервис это позволяет).
2. Сначала исправьте три существующих экрана по разделу 3, затем создавайте новые экраны по разделу 4, по одному промпту за раз.
3. Каждый готовый экран проверьте по чек-листу из раздела 6. Если пункт не выполнен, напишите в UX Pilot: «Исправь: <пункт>».
4. Утверждённые экраны экспортируйте в PNG и положите в `docs/design/mockups/` с именами из раздела 4. Программист и ИИ-агент сверяются именно с этими файлами. Если макет расходится с `BRANDBOOK.md`, побеждает брендбук, а расхождение попадает в отчёт агента.
5. Если сервис плохо понимает русский, описание можно перевести на английский, но **тексты интерфейса оставляйте русскими**, как написано в промптах.

## 5. Чего не делать

- Не придумывать функции и цифры, которых нет в продукте (ИИ-анализ, «экономия бюджета», рейтинги перевозчиков).
- Не показывать клиенту и брокеру себестоимость и внутренние документы подрядчика.
- Не рисовать чат, кабинет подрядчика и публичный лендинг: они отложены.
- Не менять скругления, шрифт и фон, они зафиксированы брендбуком.
- Не использовать цвета вне блока стиля. Если нужен новый цвет, сначала согласуйте с владельцем.

## 6. Чек-лист приёмки макета (владелец)

1. Нет текста светлее `#6B6455` и мельче 12px.
2. Основные кнопки: Coral с тёмным текстом.
3. Красный встречается только у срочного, не больше двух элементов на экран.
4. Цифры в табах, бейдже меню и списке совпадают.
5. Везде один сквозной пример, номера заявок согласованы.
6. Терминология по словарю, нет слов AI, «лид», «котировки», «перевозчики» (как раздел), нет выдуманных цифр.
7. Есть мобильные версии «Заявок», «Пульса» и «Ответа брокера».
8. Сайдбар и правая панель на всю высоту окна.
9. «Ждёт: …» всегда показывает кого и сколько.
10. У событий и документов есть метка «видно клиенту» или «внутреннее» и виден автор (человек и компания).
11. Экспортированные PNG лежат в `docs/design/mockups/` под именами из раздела 4.
