# Источники справочников и условия использования (DF-17, IC-16)

Каждый dir справочника `RefItem` имеет источник и условия использования —
требование IC-16 (§4.7) и карточки DF-17 (D37: только бесплатные официальные
и открытые источники; платные сервисы — ТКС, Альта — не подключаются).
Данные для сида живут в `scripts/ref-data/` (единственный импортёр —
`scripts/seed.ts`); перечней в логике/UI нет (IC-16).

Правка этого документа обязательна при добавлении нового dir или смене
источника: IC-16 проверяет, что каждый dir из `REF_DIRS` описан здесь.

## country — страны (ISO 3166-1)

| Параметр | Значение |
|---|---|
| Источник | ISO 3166-1: alpha-2, alpha-3 и числовой коды стран |
| Данные | полный список 249 кодов (`ISO_3166_1`, формат `alpha2\|alpha3\|числовой`), meta: `{alpha3, numeric}` |
| Русские/английские названия | генерируются при сиде через ICU (`Intl.DisplayNames`, полная ICU), терминология ВЭД переопределяется списком `RU_NAME_OVERRIDES`; имена правятся мастером на экране справочника и пересидом не перезаписываются |
| Условия использования | коды и идентификаторы — публичный стандарт; публикация ISO платная, поэтому тексты ISO не копируются: используются только сами коды (факты) и названия из ICU, а не из публикации ISO |
| Проверено (28.10.2026) | состав списка соответствует официальному ISO 3166-1 (249 записей); спец-коды (SU, AN и др. исключённые) в списке отсутствуют |

## currency — валюты (ISO 4217)

| Параметр | Значение |
|---|---|
| Источник | ISO 4217: трёхбуквенный код, число знаков после запятой (minor unit) |
| Данные | 33 ходовые в ВЭД валюты (`CURRENCY_ITEMS`), meta: `{minorUnits}`; по умолчанию активны RUB, USD, EUR, CNY (карточка DF-17), остальные включаются мастером |
| Условия использования | только коды и minor units (факты стандарта); русские подписи — собственные; таблица не копирует текст ISO 4217 |
| Проверено (28.10.2026) | minor units соответствуют стандарту: JPY/KRW/VND — 0 знаков, остальные в списке — 2 |

## packaging — упаковка (Рек. 21 ЕЭК ООН)

| Параметр | Значение |
|---|---|
| Источник | Рекомендация ЕЭК ООН № 21 «Классификатор видов груза, упаковки и упаковочных материалов» (ред. 4, 04.05.2002); русская публикация — Приложение № 15 к Приказу ФТС России от 21.08.2007 № 1003 (КонсультантПлюс) |
| Данные | 24 ходовых вида (`PACKAGING_ITEMS`) — двухбуквенные коды источника с русскими и английскими наименованиями публикации; **коды взяты из источника, не из памяти** (карточка DF-17). Остальные виды добавляются мастером через экран или в этот файл с пересидом |
| Условия использования | классификатор ЕЭК ООН — официальный открытый документ ООН; коды и наименования воспроизводятся как данные классификатора с указанием источника |
| Проверено (28.10.2026) | коды сверены с публикацией Приказа ФТС № 1003 (Рек. 21 ред. 4): BG — мешок, CT — коробка картонная, PX — поддон (паллет), CN — контейнер как транспортное оборудование и т. д.; примеры контрольных кодов совпадают |

## incoterm — условия поставки (Инкотермс 2020)

| Параметр | Значение |
|---|---|
| Источник названий | свод Инкотермс 2020 (11 терминов: EXW, FCA, CPT, CIP, DAP, DPU, DDP — любой транспорт; FAS, FOB, CFR, CIF — море и внутренняя вода); DAT — редакция 2010, в 2020 заменён DPU, хранится неактивным «по запросу» |
| Данные | `INCOTERM_ITEMS`: название термина, официальное английское полное имя, разъяснение СОБСТВЕННЫМИ словами, транспорт, placeKind, флаги правил для таможенной стоимости (`addFreightToArrival`, `addInsurance`, `deductPostArrival`, `warning`) в meta |
| Авторское право ICC | полные тексты Правил ICC не копируются и не переводятся (переводы Правил — только одобренные ICC); разъяснения в данных — независимые деловые формулировки на основе общедоступных знаний о терминах, НЕ перевод и НЕ воспроизведение текстов Правил; трёхбуквенные термины и полные английские имена используются как идентификация |
| Товарный знак | «Incoterms» — товарный знак ICC; в интерфейсе используется с символом ® где это уместно (подсказки, печатные формы) |
| Флаги правил | таблица флагов — ЧЕРНОВИК до утверждения брокером (O-12): у каждого термина `draft: true`, экран справочника показывает пометку, расчёт (DF-19) черновые правила не применяет |
| Проверено (28.10.2026) | официальная политика ICC «Incoterms® rules trademark and copyright policy» (iccwbo.org): Правила защищены копирайтом ICC; запрещено менять формулировки Правил и делать собственные переводы; при цитировании — целиком Правило; рекомендуется оговорка о товарном знаке. Наш подход: тексты не воспроизводим, разъяснения собственные |

## Курсы ЦБ РФ (CurrencyRate, не RefItem)

| Параметр | Значение |
|---|---|
| Источник | Банк России, официальная XML-выгрузка `https://www.cbr.ru/scripts/XML_daily.asp` (раздел cbr.ru/development/sxml) |
| Формат (проверено 28.10.2026) | кодировка windows-1251 (перекодируем `TextDecoder`); `date_req=дд/мм/гггг` — курс на дату, без параметра — последняя зарегистрированная дата; в шапке `ValCurs Date="дд.мм.гггг"`; на каждую валюту блок `Valute`: `CharCode` (ISO), `Nominal`, `Value` (запятая — десятичный разделитель), в новых выгрузках `VunitRate` — курс одной единицы (номинал учтён); есть XSD-схема и английская версия `XML_daily_eng.asp` |
| Время публикации (проверено 28.10.2026) | курсы устанавливаются распоряжением Банка России и публикуются, как правило, до ~15:30 МСК; установленный курс действует СО СЛЕДУЮЩЕГО календарного дня (публикации ЦБ формулируются «курсы на завтра»); в выгрузке без date_req прилетает курс последней установленной даты — импорт хранит её как есть |
| Условия использования | информация об официальных курсах — открытые данные Банка России; указание источника в интерфейсе (экран/расчёты показывают «курс ЦБ РФ от <дата>»); агентского соглашения не требуется |
| Импорт | проходом диспетчера DF-03 (`lib/cbr.ts`), раз в сутки, идемпотентен по `(date, code)`; сбой не валит проход — расчёты берут последний известный курс с пометкой даты; выключатель для CI/e2e — `CBR_IMPORT=off` |

## Ответственность за актуальность

Источники пересматриваются при каждом релизе, затрагивающем справочники:
сверка кодов с публикациями источника — по чек-листу карточки DF-17.
Изменение официальных классификаторов (новая редакция Рек. 21, обновление
Инкотермс) доезжает через `scripts/ref-data/*` + пересид; коды использованных
записей не меняются (API правки кода нет — снимки сделок остаются валидными).
